# PriceFinderAI — جستجوی هوشمند قیمت ابزار برای Android

این پروژه برای GitHub Actions آماده شده و یک APK Debug قابل نصب می‌سازد.

## قابلیت‌ها
- افزودن چندین فایل PDF قیمت ابزار با یک انتخابگر فایل.
- نمایش فایل‌های اضافه‌شده در صفحه اصلی و حذف هر فایل.
- استخراج متن PDF به‌صورت محلی با PDFBox؛ بدون نیاز به سرور.
- تشخیص تقریبی ردیف‌های قیمت، کد/مدل، نام، شرح و مشخصات از PDFهای جدولی.
- جستجوی هوشمند فارسی با نرمال‌سازی «ی/ي»، «ک/ك»، اعداد فارسی و عربی، تطبیق بخشی و فاصله و غلط تایپی.
- برای کد کالا امتیاز تطبیق بسیار بالاتر در نظر گرفته می‌شود.
- نمایش قیمت، نام، کد، شرح، مشخصات، نام فایل و شماره صفحه.
- اطلاعات داخل گوشی ذخیره می‌شود و بعد از بستن برنامه باقی می‌ماند.
- بدون API Key و بدون وابستگی به سرویس هوش مصنوعی خارجی؛ بنابراین برای GitHub Actions ساده و پایدار است.

## نکته مهم درباره PDF اسکن‌شده
اگر PDF فقط تصویر اسکن‌شده باشد و هیچ لایه متنی نداشته باشد، PDFBox نمی‌تواند متن را بخواند. نسخه پایه عمداً OCR آنلاین یا دانلود مدل بزرگ در زمان build ندارد تا مشکل Build قبلی شما با Tesseract تکرار نشود. برای PDFهای متنی/جدولی، استخراج مستقیم انجام می‌شود.

## ساخت APK در GitHub
1. کل این پوشه را در یک repository جدید قرار دهید.
2. فایل `.github/workflows/android.yml` را نگه دارید.
3. در GitHub به Actions بروید و workflow را اجرا کنید.
4. در پایان، Artifact با نام `PriceFinderAI-debug-apk` را دانلود کنید.

APK خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## ساخت محلی
Android Studio این پروژه را باز می‌کند. همچنین Gradle wrapper در پروژه قرار داده شده تا GitHub بدون نصب Gradle جداگانه build کند.
